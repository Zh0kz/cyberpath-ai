# Free educational content license scope

**License chosen for verified original free content:** [Creative Commons
Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

**Current covered works: none.** The repository owner has not yet verified the
rights to the existing educational text. This notice does not grant a CC BY
license to the current JSON files. Add a work to the covered list only after
the rights holder confirms authorship or compatible permission and approves its
attribution line.

| Existing material | Current status |
| --- | --- |
| `cyberpath_ai/academy/lessons/networking.json`, `linux.json`, `web_security.json`: authored objectives, sections, examples, summaries, quiz prompts, explanations, feedback, and hints | Rights verification pending; **not currently CC BY licensed**. |
| `cyberpath_ai/academy/skills.json`: any original skill-title wording | Rights verification pending; **not currently CC BY licensed**. |
| `cyberpath_ai/academy/resources.json`: any original `description_ru`, `objectives`, `why`, or explanatory prerequisite wording | Rights verification pending; **not currently CC BY licensed**. |
| `cyberpath_ai/academy/investigations.json`: new fictional scenario narratives, evidence, prompts, hints and explanations | No CC BY grant pending an explicit rights and licensing decision. |

Structured IDs, factual metadata, technical terms, external provider names,
course titles, URLs, and links are not claimed as CyberPath-owned creative
works. The third-party pages and media to which the catalog links are never
included in this license. News fetched at runtime is also excluded. The
[audit](docs/CONTENT_AUDIT.md) records what was inspected and what could not be
verified from repository files.

To license a verified work later, update this table with the exact path and,
where necessary, the exact fields or passages covered. Record the copyright
holder, required attribution, source permissions for adapted material, and the
date the CC BY notice first applies. Ask contributors to make the same rights
declaration in their pull requests. Future premium courses are outside this
scope and need separate explicit terms.
