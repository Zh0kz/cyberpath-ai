# Roadmap

This is a direction of travel, not a release schedule or a promise that every
item will be implemented.

## Available now

- A personal Telegram bot with a user allowlist, real source-backed news,
  optional AI explanations, an opt-in daily digest, and SQLite persistence.
- Free curated lessons in Networking, Linux, and Web Security; five-question
  quizzes, progress, adaptive lesson suggestions, spaced review, daily missions,
  and links to external learning resources.
- Offline tests and GitHub Actions CI. No active scanning of external systems.

## Planned or under consideration

- Practical challenges designed for authorized, isolated training environments.
- Clearer learning paths and more personalized recommendations across topics.
- A deployment design for multiple independent users with stronger operational
  controls, data management, and privacy documentation.
- Optional premium courses authored separately, if the project owner chooses.

There are no payments, subscriptions, user registration, or paid course
services in this repository. Original software code is under MIT. CC BY 4.0 is
chosen for original free educational text only after its rights are verified
and its scope is recorded in `CONTENT_LICENSE_SCOPE.md`; none of the existing
educational JSON is currently covered. Future premium courses would need their
own explicit terms and would not automatically inherit either license.
