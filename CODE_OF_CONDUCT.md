# Code of Conduct

CyberPath AI welcomes people learning and teaching cybersecurity at every
experience level. Treat others with respect, patience, and curiosity.

## Expected behavior

- Give constructive feedback about ideas and code, not about a person's worth.
- Explain jargon when it helps a newcomer participate.
- Credit other people's work and respect source licenses.
- Keep examples within authorized, defensive learning environments.
- Respect privacy; redact names, chat contents, tokens, and other personal data.

Harassment, discriminatory language, threats, doxxing, repeated unwanted
contact, and sharing someone's private information are not acceptable. This
applies in issues, pull requests, discussions, and other project spaces.

Maintainers may edit or remove harmful content, ask a participant to change
their behavior, or restrict participation. They will consider context and aim
for a fair, proportionate response.

For a conduct concern, contact a maintainer privately through a contact method
on their GitHub profile or use GitHub's report-abuse tools. If no private
contact is available, open a public issue asking only for a private contact
channel; do not post names, screenshots, or allegations there. Security
vulnerabilities have a separate private path in `SECURITY.md`.
